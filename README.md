# Números Ímpares em Java

## 📌 Descrição
Programa desenvolvido em Java que recebe um número inteiro e exibe todos os números ímpares de 1 até o valor informado pelo usuário.

## 🛠️ Tecnologias utilizadas
- Java
- Scanner para entrada de dados
- Estrutura de repetição `for`
- Estrutura condicional `if`

## ⚙️ Como funciona
1. O usuário digita um número inteiro.
2. O programa percorre os números de 1 até o valor digitado.
3. Utiliza o operador `%` para verificar se o número é ímpar.
4. Exibe cada número ímpar encontrado.

## 💻 Exemplo de execução

**Entrada:**
```text
10
```

**Saída:**
```text
1
3
5
7
9
```

## 🎯 Objetivo
Praticar estruturas de repetição, condicionais e o operador de módulo em Java.
